## Local Development

To test Mapoo locally, you can use [Ghps](https://github.com/sepandhaghighi/ghps) a minimal GitHub Pages simulator written in pure Python.

Run:

```console
ghps --port 5010
```

Then open your browser and visit:

```console
http://localhost:5010
```
